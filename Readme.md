# Currently Building

# InitraOS

A from-scratch operating system built step-by-step from BIOS boot to a long-term 64-bit operating-system environment.

Current implementation includes:

- BIOS bootloader and Stage 2
- Disk loading with LBA and CHS fallback
- A20 and GDT
- 32-bit Protected Mode
- VGA and serial output
- IDT, CPU exceptions and hardware interrupts
- PIT and keyboard handling
- Kernel command shell
- Kernel heap memory management
- QEMU-based testing
- GitHub Actions CI

**Current milestone:** Process & Task Management
